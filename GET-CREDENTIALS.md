# Getting ServiceNow Test Credentials

## 🎯 Free ServiceNow Developer Instance

ServiceNow offers **FREE** Personal Developer Instances (PDI) for testing!

### Step 1: Sign Up for Developer Account

1. Go to: **https://developer.servicenow.com/**
2. Click **"Sign up and Start Building"**
3. Fill in the registration form:
   - Email address
   - First/Last name
   - Create password
4. Verify your email
5. Complete your profile

### Step 2: Request a Personal Developer Instance

1. Log into: **https://developer.servicenow.com/**
2. Click **"Request Instance"** (top right)
3. Select instance release (choose latest, e.g., "Xanadu" or "Washington DC")
4. Click **"Request"**
5. Wait 2-5 minutes for instance to be created

### Step 3: Get Your Credentials

Once your instance is ready, you'll see:

```
Instance URL: https://dev123456.service-now.com
Username: admin
Password: [click "Show Password" to reveal]
```

**Important:** 
- Your instance URL will be something like `dev123456.service-now.com`
- The username is always `admin`
- Password is auto-generated (you can reset it)

### Step 4: Configure Your .env File

Copy these credentials to your `.env` file:

```env
# ServiceNow Configuration (from your PDI)
SERVICENOW_INSTANCE_URL=https://dev123456.service-now.com
SERVICENOW_USERNAME=admin
SERVICENOW_PASSWORD=YourAutoGeneratedPassword123!

# OpenAI API Key (get from https://platform.openai.com/api-keys)
OPENAI_API_KEY=sk-proj-your-key-here

# SSO Configuration (use any URL for testing)
SSO_SIGNIN_URL=https://sso.example.com/login

# Agent Settings (30 seconds for quick testing)
TICKET_CHECK_INTERVAL=30000
AUTO_RESOLVE_TICKETS=false
ACCESS_KEYWORDS=access,login,sign in,authentication,SSO,password,credentials
```

## 🔑 Complete .env Example

Here's a **ready-to-use** `.env` file template:

```env
# ============================================
# ServiceNow Personal Developer Instance
# ============================================
# Get free instance at: https://developer.servicenow.com/
# Replace with YOUR instance details:

SERVICENOW_INSTANCE_URL=https://dev123456.service-now.com
SERVICENOW_USERNAME=admin
SERVICENOW_PASSWORD=YourPasswordHere

# ============================================
# OpenAI API Configuration
# ============================================
# Get API key at: https://platform.openai.com/api-keys
# Make sure you have credits available

OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# ============================================
# SSO Configuration
# ============================================
# For testing, you can use any URL
# In production, use your actual SSO portal

SSO_SIGNIN_URL=https://sso.yourcompany.com/login

# ============================================
# Agent Configuration
# ============================================

# How often to check for tickets (in milliseconds)
# 30000 = 30 seconds (good for testing)
# 300000 = 5 minutes (good for production)
TICKET_CHECK_INTERVAL=30000

# Auto-resolve tickets after responding?
# false = Leave tickets open for human review (recommended for testing)
# true = Automatically set tickets to "Resolved" state
AUTO_RESOLVE_TICKETS=false

# Keywords to detect access issues (comma-separated)
# Agent will respond to tickets containing these words
ACCESS_KEYWORDS=access,login,sign in,authentication,SSO,password,credentials,locked out,cannot access
```

## 🧪 Test Your Configuration

### Verify ServiceNow Connection

You can test your ServiceNow credentials manually:

```bash
# Test with curl (replace with your credentials)
curl -u admin:YourPassword \
  "https://dev123456.service-now.com/api/now/table/incident?sysparm_limit=1"
```

If successful, you'll get JSON response with incident data.

### Verify OpenAI API Key

```bash
# Test with curl (replace with your API key)
curl https://api.openai.com/v1/models \
  -H "Authorization: Bearer sk-proj-your-key"
```

If successful, you'll get a list of available models.

## ❓ Troubleshooting

### "Instance not found" error
- Check the URL format: `https://dev123456.service-now.com` (no trailing slash)
- Make sure instance is active (check developer portal)

### "401 Unauthorized" error
- Verify username is `admin`
- Check password (copy-paste from developer portal)
- Password may have special characters - copy exactly

### "Instance hibernated" message
- Developer instances hibernate after inactivity
- Go to developer portal and click "Wake Up Instance"
- Wait 2-3 minutes for instance to wake up
